# Ври убедительно

## Проверка живой компанией

Один организатор скачивает этот репозиторий, устанавливает [Node.js 22+](https://nodejs.org/) и запускает из папки игры команду ниже. Зависимостей нет, устанавливать пакеты не требуется. Остальные участники открывают игру в браузере; каждый отвечает со своего устройства. Минимум три игрока.

1. Организатор выполняет `node server.mjs`. Терминал оставляет открытым.
2. Для устройств в одной Wi-Fi/локальной сети: узнайте IPv4 компьютера командой `ipconfig` и откройте `http://ЭТОТ-IP:4176` на всех устройствах. При первом запуске разрешите Node.js доступ в частной сети в брандмауэре Windows. Гостевая Wi-Fi-сеть может изолировать устройства.
3. Организатор создаёт обычную комнату и копирует ссылку из лобби. Остальные входят по ней со своими именами. Ссылка с `localhost` работает только на компьютере организатора — для телефонов нужен адрес из шага 2.
4. Хост начинает партию. Через «Меню → Открыть общий экран» можно открыть отдельную вкладку для телевизора или трансляции: это зрительский экран без личного ответа и секретного слова. Ответы вводятся на устройствах игроков.
5. Для проверки повторного подключения обновите вкладку игрока. Для проверки передачи роли хоста выйдите из комнаты через меню — управление перейдёт другому участнику.

## Проверка из разных городов

Нужен один доступный через интернет Node.js-сервер. Каждый участник **не должен запускать свою копию сервера**: это создаст независимые комнаты. Сам репозиторий не является игровой ссылкой.

Бесплатный вариант — [Render Free](https://render.com/docs/free). В репозитории есть `render.yaml`:

1. Опубликуйте код в своём GitHub-репозитории и подключите его в Render через **New → Blueprint**. Альтернатива: **New → Web Service**, среда Node, тариф Free, сборка `node --version`, запуск `npm start`.
2. Render выдаст HTTPS-адрес вида `https://имя.onrender.com`. Отправьте его участникам. Создайте обычную комнату и поделитесь её ссылкой. Участникам не нужны Node.js, GitHub или аккаунт Render.
3. В Blueprint тестовые боты отключены через `TEST_BOTS=0`. Реальные игроки подключаются к одному серверу. Для общего экрана по-прежнему доступен пункт меню у хоста.

На Free сервер засыпает после 15 минут без запросов; первый запуск после простоя может занять около минуты. Комнаты хранятся в памяти: сон, перезапуск или новая публикация сбрасывают партии. Используйте один экземпляр сервиса. Создавайте комнату после пробуждения сервера; сохранность старой комнаты не гарантируется. Это вариант для демонстрации, а не постоянного хранения партий.

Без аккаунта можно использовать [Cloudflare Quick Tunnel](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/): установите `cloudflared`, запустите игру и во втором терминале выполните `cloudflared tunnel --url http://127.0.0.1:4176`. Откройте выданный HTTPS-адрес, создайте комнату уже по нему и отправьте ссылку участникам. Адрес работает, пока включены компьютер, сервер и туннель, и меняется при перезапуске туннеля.

## Быстрый запуск на компьютере


Сетевая игра на 3–8 человек по мотивам [Fibbage: Enough About You](https://www.jackboxgames.com/blog/introducing-fibbage-enough-about-you). Игроки выпускают жёлтую газету друг о друге.

```powershell
node server.mjs
```

Откройте http://127.0.0.1:4176. Хост создаёт комнату и делится ссылкой или кодом. Для игры с телефонов в одной сети откройте лобби по локальному IP компьютера с сервером.

В начале у каждого 40 секунд на тайный честный ответ. Редакция выпускает по одной заметке на каждое сданное интервью. Остальные игроки за 35 секунд сочиняют версии, затем за 25 секунд голосуют за правду. Герой выпуска ждёт раскрытия. При нехватке выдумок редакция добавляет свои версии.

Во время голосования все видят одни и те же карточки. Аватар игрока появляется на выбранной карточке сразу после принятия голоса. Когда все проголосовали или истёк таймер, на тех же карточках открываются правда и авторы выдумок.

За угаданную правду начисляются два очка, за каждый голос за свою выдумку или свой честный ответ — одно. При равном счёте победа общая. Финал состоит из первой полосы с победителем, главной утки номера и архива.

Кнопка «Тест с ботами» создаёт комнату с тремя ботами. Чтобы отключить режим, запусти сервер с `TEST_BOTS=0`. В «Меню» находятся выход из комнаты и отдельные настройки громкости музыки и эффектов.

Музыка — [Local Forecast](https://incompetech.com/music/royalty-free/index.html?isrc=USUAN1300010), Kevin MacLeod, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Эффекты [печатной машинки](https://assets.mixkit.co/active_storage/sfx/1386/1386-preview.mp3), [отсчёта](https://assets.mixkit.co/active_storage/sfx/1061/1061-preview.mp3) и [барабанной дроби](https://assets.mixkit.co/active_storage/sfx/577/577-preview.mp3) от Mixkit.

Клиент использует HTML, CSS и JavaScript. Node.js 22+ обслуживает комнаты без внешних зависимостей. В `src/game.mjs` находятся правила и счёт, в `src/content.mjs` — вопросы и ответы. До раскрытия сервер показывает только анонимные варианты.

## Проверки

`npm test` проверяет полную партию, скрытие секретов на общем экране, повторный запуск, независимые HTTP-сессии, восстановление подключения и передачу хоста. Тесты используют локальные временные серверы без внешних зависимостей.
