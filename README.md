# Ври убедительно

Сетевая игра на 3–8 человек по мотивам [Fibbage: Enough About You](https://www.jackboxgames.com/blog/introducing-fibbage-enough-about-you). Игроки выпускают жёлтую газету друг о друге.

```powershell
node .\vri-ubeditelno\server.mjs
```

Откройте http://127.0.0.1:4176. Хост создаёт комнату и делится ссылкой или кодом. Для игры с телефонов в одной сети откройте лобби по локальному IP компьютера с сервером.

В начале у каждого 40 секунд на тайный честный ответ. Редакция выпускает по одной заметке на каждое сданное интервью. Остальные игроки за 35 секунд сочиняют версии, затем за 25 секунд голосуют за правду. Герой выпуска ждёт раскрытия. При нехватке выдумок редакция добавляет свои версии.

За угаданную правду начисляются два очка, за каждый голос за свою выдумку или свой честный ответ — одно. При равном счёте победа общая. После голосования хост листает утки, которым поверили, и последней открывает правду. Финал состоит из первой полосы с победителем, главной утки номера и архива.

Кнопка «Тест с ботами» создаёт комнату с тремя ботами. Чтобы отключить режим, запусти сервер с `TEST_BOTS=0`. В «Меню» находятся выход из комнаты и отдельные настройки громкости музыки и эффектов.

Музыка — [Local Forecast](https://incompetech.com/music/royalty-free/index.html?isrc=USUAN1300010), Kevin MacLeod, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Эффекты [печатной машинки](https://assets.mixkit.co/active_storage/sfx/1386/1386-preview.mp3), [отсчёта](https://assets.mixkit.co/active_storage/sfx/1061/1061-preview.mp3) и [барабанной дроби](https://assets.mixkit.co/active_storage/sfx/577/577-preview.mp3) от Mixkit.

Клиент использует HTML, CSS и JavaScript. Node.js 22+ обслуживает комнаты без внешних зависимостей. В `src/game.mjs` находятся правила и счёт, в `src/content.mjs` — вопросы и ответы. До раскрытия сервер показывает только анонимные варианты.
